CanSell（能卖哪）是面向中国出海制造商的全球商品准入 Agent。上传商品目录后，系统按 SKU × 国家 × 平台 × 法规给出 PASS / WARNING / BLOCKED / UNCERTAIN / EXPERT_REVIEW_REQUIRED，并绑定官方来源、条款、缺失项和下一步行动。法规变化时不推送新闻，只告诉你目录里哪些 SKU 被打中。

中国出口企业不缺法规信息，缺的是规则打到自己哪些商品。现有工具是碎片化的：平台规则中心只管自家上架，RegASK / Enhesa 面向大型企业，检测机构做单次测试，Excel 无法跟踪变更。CanSell 不做法规搜索或聊天机器人，而做可验证的市场准入状态机。LLM 不能单独作为证据。

MVP 只覆盖可验证子集：消费电子（蓝牙音箱、LED 灯）加一条化妆品对照 SKU；市场欧盟、美国、印度尼西亚；平台 Alibaba.com 与 Amazon。演示闭环：CSV 目录 → 商品数字孪生 → 官方规则匹配 → 证据矩阵 → 整改清单 → 再检查；以及一次法规版本变更后的 SKU 影响。

本作品不是法律意见。代码 MIT 开源，含 FastAPI 引擎、矩阵 UI 与 pytest。
