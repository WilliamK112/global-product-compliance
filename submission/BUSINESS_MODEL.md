# 商业模式

定价未对客户成交，以下是设计而非已收费价目。RegASK / Enhesa / 欧税通的 SKU 引擎公开价均为 **Not publicly disclosed**。

## 谁付钱

- User：外贸专员 / 认证工程师
- Buyer：中小制造企业老板 / 总经理
- Decision maker：老板；高风险时品质/法务会签

## 收费层

| 档位 | 范围 | 用途 |
|---|---|---|
| Free | 1 SKU × 1 市场 | 获客。水印：非法律意见 |
| Pro | 100 SKU × 5 市场 + 变更监控 | 广东电子出口工厂 |
| Enterprise | 10k SKU × 多市场 × API × PIM/ERP | 集团目录、审计日志、SSO |
| API | 按 SKU check / 国家包 / 监控事件 | 嵌入 ERP |
| Expert marketplace | 检测、欧盟责任人、BPOM 持证方、律师 | 推荐抽成，同时是责任缓冲 |

## 为什么会付钱

一次 Amazon 下架或一次扣关，通常高于 Pro 年费。产品卖的是「哪些 SKU 要立刻动」，不是法规新闻。

## 不绑死阿里

CSV 是通用入口。Alibaba 是第一生态，Amazon / TikTok / Temu / SHEIN / Shopify / ERP 是后续通道。
