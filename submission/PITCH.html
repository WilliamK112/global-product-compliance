中国出口真正的问题

一个广东工厂同时面对数十个市场、平台和法规。

他们不是不知道海外有法规，而是不知道这些法规会打到自己的哪些 SKU。

现有工具为什么失败

  • Marketplace rules：只管自家上架
  • RegASK / Enhesa：企业级情报，不是中国工厂目录
  • 检测机构：一次测一个型号
  • 律师 / 规海星图：搜法条
  • Excel：法规一变全表失效

核心产品

Product × Country × Platform × Regulation = Market Access State

PASS / WARNING / BLOCKED / UNCERTAIN / EXPERT REVIEW REQUIRED

不是 Yes / No，更不是聊天。

Product Digital Twin

SKU、品类、HS 候选、材料、无线、电池、认证、标签、产地。

图片线索只是候选，人工确认前不得当事实。

Regulatory Graph

官方 URL、条款、生效日、版本、哈希、摘录。

MVP 只覆盖可验证子集：EU / US / 印尼 × 消费电子 + 一条化妆品对照。

Compliance Matrix

蓝牙音箱：EU/US/ID 因缺 RED / FCC / DJID 为 BLOCKED。

LED：EU/US WARNING，印尼在现有 SNI 证据下 PASS。

精华液：印尼无 BPOM Notifkos 为 BLOCKED。

结果由属性计算，改 SKU 名不会变。

法规变化影响

不要告诉工厂「出了一部新法」。

要告诉工厂：3 个 SKU 里有 1 个被打中。LED 印尼 PASS → WARNING。

Agent 架构

Intake → Research → Match → Verify → Action → Re-check。

验证金字塔：官方法规 > 主管机关指南 > 平台规则 > 标准 > LLM > 专家。

LLM 在最下层，不能单独主张。

市场与竞品

不是首创监管 AI。RegASK / Amazon 已经存在。

空白是：中国出口商目录 × 跨平台 × SKU 级影响 × 整改闭环。

付钱的是工厂老板，每天用的是外贸/认证岗。

商业模式

Free：1 SKU × 1 市场。

Pro：目录 + 监控。

Enterprise：API / PIM。

专家市场：检测、欧盟责任人、BPOM 持证方。不是律所。
